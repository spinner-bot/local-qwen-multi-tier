# local-qwen-multi-tier

sqs_A100 服务器上的**多档位本地 Qwen 部署与文件管理仓库**。

## 用途

- 统一管理本地 LLM 的权重清单、服务配置与启停脚本
- 支持按「任务类型 × 资源紧张度」路由到不同规模模型
- 权重本体与运行环境不入库，仅记录清单与配置

## 目录约定

| 路径 | 内容 | 是否入库 |
|---|---|---|
| `models.tsv` | 模型注册表（档位/来源/路径/TP/端口/用途） | 是 |
| `config/` | 服务配置（vLLM / 网关） | 是 |
| `scripts/` | 启停、状态、路由辅助脚本 | 是 |
| `/data/Users/zrh/models/` | 权重文件（仓库外） | 否 |
| `/data/Users/zrh/.envs/envs/vllm/` | 运行环境（仓库外） | 否 |

## 档位规划

| 档 | 模型 | 用途 |
|---|---|---|
| T0 | Qwen3-4B | 冒烟、分类、短摘要、兜底 |
| T1 | Qwen3-8B | 常驻轻任务 |
| T2 | Qwen3-14B | 通用主力 |
| T3 | Qwen3-30B-A3B | 高吞吐批处理 / agent |
| T4 | Qwen3-32B (bf16/AWQ) | 质量主力 |
| T5 | Qwen3-72B | 高难推理、长文 |
| T6 | Qwen3-235B-A22B (int4) | 天花板，按需独占 4 卡 |

## 资源约束

- 本机 8×A100-PCIE-40GB，组内约定每人最多 4 卡，优先 0–3
- 无 NVLink，多卡只用 TP2/TP4（同组内）
- 服务一律绑定 `127.0.0.1`，经 SSH 隧道访问
